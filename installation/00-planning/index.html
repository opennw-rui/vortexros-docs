部署规划

首装需要 Ubuntu 26.04 amd64、可访问的 APT 软件源和当前版本的单文件安装器。见首次安装。

场景

选择

影响

初次试用或虚拟机

使用默认 Linux 数据面

网卡保持 Linux 驱动

专用业务口

验证基本连通性后启用 DPDK

所选网卡会换驱动，转发可能短暂中断

单网卡远程设备

先确认独立恢复通道

SSH 可能随驱动切换而中断
