支持的硬件

本页对应 VortexROS 0.28 开发版 Debug 9、配套 VPP 26.10.4 和 DPDK 26.07。选型时先看本版安装范围，再按 PCI ID、驱动和实际用途确认网卡。内核驱动、PCI 绑定驱动和 DPDK PMD 是三项独立信息。

Proxmox VE（PVE）VirtIO 网卡

虚拟机网卡模型选 VirtIO (paravirtualized)，虚拟机中的 Linux 驱动为 virtio_net。虚拟机若使用 DPDK，对应独立的 Virtio PMD

上游有驱动。PVE 宿主桥接、虚拟机中的 Linux 转发和虚拟机中的 DPDK 是不同路径。目前无 PVE 专项验收记录。

N5105 产品规格 · DPDK 26.07 IGC · DPDK 26.07 平台验证 · Proxmox VE 虚拟机手册 · DPDK 26.07 Virtio

在 Proxmox VE 中选择 VirtIO

在虚拟机的 硬件 → 网络设备 中选择 VirtIO，并将设备接到所需的 PVE bridge。按 Linux 模式首装后，在虚拟机内运行 ethtool -i，确认驱动为 virtio_net，再通过 display interface brief 核对接口。虚拟机中的 DPDK 仍须独立验证 PCI 设备识别、IOMMU／VFIO 条件及管理路径。

FD.io VPP 支持范围

FD.io VPP 列出 x86‑64 和 Arm AArch64 两种架构，软件包支持近期 Debian 和 Ubuntu 版本。DPDK 的 x86 平台包括 Intel 和 AMD，另有 Arm 平台。VortexROS 本版单文件安装器面向 Ubuntu 26.04 amd64。VPP 的架构支持范围可用于评估底层能力，产品安装包和各功能的验收范围以支持矩阵为准。

VPP 的硬件驱动由 FD.io CSIT 性能用例覆盖。走 VPP 原生驱动时查 VPP 功能清单；走 DPDK 时查配套版本的 PMD 指南和设备 PCI ID。下表是常见选型入口，完整厂商列表见 DPDK 驱动目录。

核对自己的设备

在 Ubuntu 终端查看 CPU、网卡 PCI ID 和当前驱动。若为 PVE VirtIO，以下命令在虚拟机内执行，并用实际接口名替换 ens18。

lscpu
lspci -nnk
ethtool -i ens18

在 VortexROS CLI 用 display dataplane interfaces 核对期望模式和活动模式，再用 display interface hardware offload 查看具体网口的硬件能力。DPDK 接管前按数据面配置核对 PCI、IOMMU、大页和管理连接。接管后按硬件验收检查实际链路、业务和恢复。
