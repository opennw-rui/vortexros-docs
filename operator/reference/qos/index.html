QoS

配置指南

qos lr

  • 类别：配置命令

  • 视图：VLAN视图、接口视图

  • 用途（设备帮助）：configure interface or VLAN rate limit (2-rate 3-color)

  • 合法语法：

    qos lr { inbound | outbound } cir CIR [pir PIR] [cbs CBS] [pbs PBS] [green|yellow|red pass|discard]

参数与子命令

  • 数据来源：Candidate（本会话待提交配置）。 适用分区：interface/ethernet-neutral, interface/ethernet-l2, interface/ethernet-l3, interface/eth-trunk-neutral, interface/eth-trunk-l2, interface/eth-trunk-l3, interface/subif-l2, interface/subif-l3, interface/tunnel-pending, interface/tunnel-gre, interface/tunnel-wireguard, interface/tunnel-amneziawg, interface/loopback, interface/vlanif, interface/vbdif, interface/ethernet-aggregate-member
