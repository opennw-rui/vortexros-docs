memory hugepages

  • 类别：配置命令

  • 执行效果：修改当前会话配置；提交后保存；通过 reset dataplane 生成启动设置，并按提示重启主机后生效。

  • 视图：dataplane

  • CLI 帮助：Reserve huge pages at boot

  • 合法语法：

    memory hugepages size { 2M | 1G } count NUMBER [numa NODE]

参数与子命令

  • 数据来源：Candidate（本会话待提交配置）。

参数位置

关键字 / 参数

CLI 帮助含义

输入方式

命令后

size

Page size

关键字

size

SIZE

2M or 1G

输入值

SIZE

count

Number of pages

关键字

count

NUMBER

大页页数，范围 1–4294967295

输入值

NUMBER

numa

指定 NUMA 节点，可省略

关键字

numa

NODE

NUMA 节点编号，省略为 0

输入值

NODE 为 NUMA 节点编号，省略时为 0。重复配置替换该节点页数；不改变其他节点。同一配置使用一种页大小。页数必须大于 0。节点必须实际存在，预留量应小于该节点可提供的内存。参见逐节点配置与查询。
