配置指南

bridge-domain

  • 类别：配置命令

  • 执行效果：修改当前会话配置；执行 commit 成功后生效。

  • 视图：系统视图（也可从其他配置视图直接调用）

  • CLI 帮助：add the interface to a bridge-domain；create a bridge-domain and enter its view

  • 合法语法：

    bridge-domain ID

    bridge-domain ID [bvi]

参数与子命令

  • 数据来源：Candidate（本会话待提交配置）。

适用视图：interface 接口类别：Ethernet、Eth-Trunk、子接口、LoopBack、隧道 接口类别：Ethernet（未选择二/三层）、二层 Ethernet、二层子接口、Eth-Trunk（未选择二/三层）、二层 Eth-Trunk
