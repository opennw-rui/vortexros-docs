路由表与 FIB

配置指南

display ip fib

  • 类别：只读显示命令

  • 执行效果：显示设备配置或运行状态，不修改配置。

  • 视图：任意允许视图

  • CLI 帮助：display the effective VPP IPv4 forwarding table

  • 合法语法：

    display ip fib [vpn-instance VRF]

参数与子命令

  • 数据来源：后端运行态。
