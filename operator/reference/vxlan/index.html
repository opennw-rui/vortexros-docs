display vxlan statistics

  • 类别：只读显示命令

  • 执行效果：显示设备配置或运行状态，不修改配置。

  • 视图：任意允许视图

  • CLI 帮助：display VXLAN tunnel traffic statistics

  • 合法语法：

    display vxlan statistics source IP peer IP [vni VNI]

  • 数据来源：后端运行态。
