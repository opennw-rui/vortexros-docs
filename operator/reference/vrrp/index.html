VRRP

配置指南

display vrrp

  • 类别：只读显示命令

  • 视图：任意允许视图

  • 用途（设备帮助）：display IPv4 VRRPv3 information

  • 合法语法：

    display vrrp [brief|interface INTERFACE|statistics|protocol-information|VRID]

参数与子命令

  • 数据来源：后端运行态。

undo vrrp vrid

  • 类别：配置命令

  • 视图：接口视图

  • 用途（设备帮助）：delete or reset an IPv4 VRRPv3 group

  • 合法语法：

    undo vrrp vrid INTEGER<1-255> [...]
