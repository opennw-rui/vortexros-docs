硬件卸载

查看网卡/驱动能力与当前启用状态，只有产品提供的控制项才可用CLI修改。

display interface hardware offload Ethernet 1

列

含义

Supported

驱动报告支持该能力，不代表已开启

Active

实际启用状态，不能由配置推断

Control=online

产品可在线控制的能力

Control=disabled

对应产品控制项已显式禁用

Control=driver

由驱动决定，当前CLI不提供逐项开启入口

同一份接口策略可在接口视图和dataplane设备视图编辑，不是两份独立配置。当前可配置项以hardware offload ?为准，包括GSO、TSO、收发校验和与多段报文。关闭RX/TX校验和前，需在同次命令先关闭依赖它们的TSO。

system-view
interface Ethernet 1
 undo hardware offload gso
quit
commit
display interface hardware offload Ethernet 1

恢复使用 hardware offload gso 并提交。恢复默认不保证每个驱动细项都变成Active=yes，未开放控制的driver项仍按驱动实际状态显示。GSO是软件分段，TSO是硬件TCP分段，二者不是同一层功能。

修改后检查Active列；需要重新初始化驱动的项目应按提示重建数据面。操作步骤见数据面激活与恢复。
