路由优先级

同一目标前缀存在多条路由时，先比较前缀长度，再在可用的同前缀候选中比较路由优先级；数值越小越优先。同一协议的 Cost、RIP 跳数和 BGP 选路属性参与各自协议的路径选择，不能与系统优先级混为一个数值。

RIP 可配置 preference；RIPng 当前使用固定默认值

OSPF / OSPFv3 外部路由

150

当前固定默认值

BGP（外部、内部及本地产生）

254

当前固定默认值

这是当前 VortexROS 的产品默认值。默认项省略于配置显示；明确修改后才显示相应配置。BGP 默认值为 254，不应根据其他系统的默认值推断为 255。

如何核对

display ip routing-table 172.29.251.2 32
display ipv6 routing-table 2001:db8:251::2 128
display ip fib
display ipv6 fib

真实同前缀对照中，RIP 路由显示 Preference 100、Cost 2；启用 OSPF 并学到相同前缀后，选中路由显示 OSPF、Preference 10、Cost 20。撤销 OSPF 后，应再次检查候选路由、FIB 和连通性，而不只检查 OSPF 配置已经删除。

另一次外部路由验证中，OSPF 导入静态路由时指定 cost 37、type 2，LSDB 明细显示 E type 2、Metric 37、Len 36；路由表显示 Preference 150、Cost 37。

协议数据库出现路由不代表该路由最终胜出或已安装。FIB 显示中的路径优先级属于转发表的路径选择字段，与本页的路由管理优先级不同；最终以路由表的 Pre/Preference 和 FIB 的实际出口分别核对。

修改影响

调整优先级可能让相同前缀切换到另一协议及出口。先核对备选路由及回程，再提交。RIP 修改后，已有学习路由可在后续协议更新中重新参与选路，提交成功不等于全部前缀已立即完成切换。检查实际路由状态后再保存。
