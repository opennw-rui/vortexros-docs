创建与地址族

RD区分VPN路由身份，RT决定导入导出，两者不代替接口路由表隔离。BGP VPN地址族复用此处RD/RT。

配置

以下为功能片段，接口、引用对象及对端须先按完整案例准备。未创建的依赖会被拒绝。

system-view
ip vpn-instance BLUE
 ipv4-family
  route-distinguisher 65000:100
  vpn-target 65000:100 both
 quit
 ipv6-family
 quit
quit
commit

查询与实际效果

display ip vpn-instance

案例的真实 display、报文或路由结果与本节功能相互对应。该功能片段是参数说明，不将这里的演示地址冒充另一组已经执行的输出。对照配置、后端实际状态和业务三者，不能只看commit返回。

撤销

先解除消费者引用，再按以下片段撤销当前对象或开关；不要删除仍被其他业务使用的共享对象。

system-view
undo ip vpn-instance BLUE
commit

再次查询实际状态和新业务，确认后执行save。只提交未保存的变化不会在重启后作为启动配置恢复。
