# 命令参考

本参考列出当前版本实际提供的CLI。每条命令路径只出现一次；同一命令在不同视图中的合法写法会合并展示。配置命令先保存在当前登录会话中，执行 `commit` 成功后生效；显示命令不会改变设备配置。

本参考包含 **820** 条规范命令路径。
