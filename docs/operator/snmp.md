# SNMP

通过 SNMP 查询设备状态和接口计数。

[命令参考](reference/snmp.md) · [配置案例](../examples/snmp.md)

## 工作原理与访问范围

SNMP 允许外部管理系统读取设备对象及接口计数。管理端发起查询，设备按版本、凭据、权限和监听范围应答；SNMP 服务不等于设备已经配置了外部监控平台。

使用 community 的版本依靠相应字符串控制访问；需要认证和隐私保护时优先按 SNMPv3 页面配置，并区分认证与加密算法。应只允许可信管理网络访问，不能把外部平台无法查询都归因于设备计数故障。

接口索引属于查询对象身份，业务接口名称及流量方向仍按设备显示解释。验证凭据和来源限制、代表对象、计数增长及撤销后的访问结果；不要在公开配置或工单中暴露有效凭据。
