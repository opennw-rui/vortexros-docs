# 管理会话

使用`display users`查看已登录用户、角色和会话状态：

~~~text
display users
~~~

需要断开某个受管账号的会话时执行：

~~~text
reset aaa user admin sessions
~~~

按提示确认后，该账号当前的受管SSH/CLI会话关闭。此操作不删除账号或密码；账号仍为活跃状态时可重新登录。需要禁止再次登录，在账号视图配置`undo active`并提交。

执行前确认目标账号，避免关闭自己的唯一管理连接。root救援入口不作为普通受管账号会话清理对象。

## 断开后重新登录

一次只读账号的实际 SSH 验证中，重置命令关闭了该账号的一个现有会话，管理员连接保持。账号仍为 active，随后重新登录成功；删除账号并提交后，后续受管会话也被关闭。验证断开会话时，应同时核对账号是否仍存在，避免把“会话已关闭”误认为“账号已禁用”。


一次实际 SSH 会话验证中，目标 operator 的当前会话被关闭，root 管理连接保留；账号仍为活跃状态，随后可以重新认证登录。若目标是禁止账号继续使用，应修改账号状态或删除账号并提交，而不是仅清会话。用 `display users` 区分账号是否活跃和当前是否在线。
