# 学习与默认行为

## 默认行为

启用交换功能后，每个VLAN对应的转发域默认采用以下行为：

- 动态MAC学习：开启；
- 广播和组播泛洪：开启；
- 未知单播泛洪：开启；
- 二层转发：开启；
- 动态MAC老化时间：300秒。


[功能目录](../mac-table.md) · [命令参数](../reference/bridge-domains.md)


## 清除动态 MAC

~~~text
reset mac-address interface Ethernet 1 mac-address 02-00-00-00-00-03
display mac-address
~~~

按提示确认后，只清除选择范围内的动态 MAC，静态 MAC 保留。若设备继续收到来自该地址的报文，表项可能立即重新学习，因此“清除后又出现”不一定是删除失败。

实际双端验证先停止目标端发送，清除后查询确认目标动态项消失、对照静态项保留；恢复目标端发送后，动态项重新学习，二层探测 3/3。清除表项不关闭接口，也不删除 VLAN。


清除的动态项若仍在收到源报文，可以很快重新学习；这与清除失败不同。需要验证某个指定 MAC 的删除时，先让对应发送端停止发包，再清表和查询；保留一个静态项作为对照。实际验证中，指定动态项从查询与转发表中消失，静态项保留；恢复发送后，动态项重新学习，双端探测3/3。
