# 路由策略

前缀列表负责匹配，route-policy 节点允许、拒绝或修改路由。定义不等于启用，只有在协议消费者挂载后才生效。

## 工作原理与生效位置

路由策略在路由导入、导出或协议选择时匹配并处理路由，操作对象是路由及属性，不是逐包业务流。节点顺序、permit/deny、匹配条件与执行动作共同决定结果。

前缀列表匹配目标前缀和长度，AS 路径、团体等条件匹配对应 BGP 属性。策略必须挂到本手册列出的协议入口才生效；名字相同不表示已被所有协议自动引用。ACL 的报文过滤与路由策略的前缀过滤不能互换。

适合控制重分发范围、对外发布集合和 BGP 属性。先列出应允许及应拒绝的代表路由，再变更；修改已引用策略会影响现有路由，删除前先撤销引用，核对路由发布和业务变化。
