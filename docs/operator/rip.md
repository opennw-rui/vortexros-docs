# RIP

支持 RIPv1 和 RIPv2 的 IPv4 路由交换。当前配套FRR 缺省优先级为 100，可在进程视图用 `preference <值>` 调整。默认 100 不显示在配置中；`undo preference` 恢复默认。修改优先级后，已有路由在后续 RIP 更新时重新选路，应以实际路由表为准。

[命令参考](reference/rip.md) · [配置案例](../examples/rip.md)

## 工作原理与使用边界

RIP 是距离矢量协议。RIPv2（RFC 2453）以跳数作为度量，16 表示不可达，最多 15 个有效跳；周期更新和超时机制使故障检测与恢复通常慢于链路状态协议。适合较小或兼容性优先的 IPv4 网络。

RIPv1 不携带子网掩码；需要无类前缀时选用 RIPv2，并让两端版本、接口启用范围和认证一致。路由优先级默认 100 与跳数是不同字段。使用 BFD 可缩短故障发现，但不会替代正确的 RIP 路由发布与撤销。

配置后分别核对接口是否参加协议、收到的路由、系统选路和实际出口。关闭接口或撤销 network 后，路由应随协议收敛撤销；保留静态或其他协议的同前缀路由时，需要检查来源，不能只按目的地址判断。
