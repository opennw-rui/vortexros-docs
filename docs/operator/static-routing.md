# 静态路由

固定下一跳、黑洞和跨表查询具有不同的数据面含义；按业务选择，不通过近似写法静默改变路由所有权。

## 工作原理与路径选择

静态路由把目标前缀交给指定下一跳、接口或显式查表动作。最长前缀匹配决定命中哪条路由，同一前缀的候选再按优先级等条件选择。默认 Preference 为 60；配置固定下一跳不等于下一跳一定可解析。

普通递归路由依赖到下一跳的可用路由；显式查表路由把查找交给另一张表，两者的语义不同。黑洞路由用于有意丢弃指定前缀，不能用来证明远端可达。多条等价路径需要分别核对每个出口及下一跳。

适合固定出口、默认路由或少量明确业务前缀。变更可能立即切换业务出口，删除前应确认替代路径和回程。验证同时查看配置、选中路由、FIB 与双向业务；没有进入 FIB 时先查下一跳依赖。
