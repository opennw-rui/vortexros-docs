# 手册适用范围

本手册适用于VortexROS 0.30-dev。软件组件及版本见[软件组成](../installation/02-backends.md)。请先核对设备的`display version`，再使用对应版本的命令。

## 按任务查阅

- 首次安装：阅读[安装](../installation/index.md)，通过单文件安装器完成安装，再按[入门](../quickstart.md)建立基本连通。
- 配置功能：从侧栏进入对应功能页，先看前提、默认行为和影响，再执行配置。
- 搭建网络：使用[配置案例](../examples/index.md)，按角色分别配置CE、PE、P及对端。
- 查询语法：使用[命令参考](../operator/reference/commands.md)，或在设备当前视图输入`?`。
- 定位问题：从[常见故障](../troubleshooting/index.md)检查接口、邻居、路由和服务状态。

## 示例约定

案例中的路由器均为VortexROS。`Ethernet0`、`Ethernet1`表示各设备上的独立接口，相同名称位于不同设备时不是同一个端口。子接口使用`Ethernet0.100`形式；LoopBack、Vlanif、Vbdif、Eth-Trunk和Tunnel使用产品自身的接口名称。

请将示例地址、接口编号、AS号、VPN名称和密钥替换为自己的规划值。同一案例内应同时修改拓扑、两端配置及验证命令，不能只改一侧。

配置块中的命令按顺序执行；输出块用于说明应观察的状态。输出中的地址和接口与案例保持一致，计数、运行时间、动态分配地址等以设备实际结果为准。

## 配置生命周期

修改先进入当前会话的Candidate，`commit`后成为Running，`save`后写入启动配置。案例的撤销步骤只删除该案例新增内容；共用接口、底层路由和协议进程应保留。

手册只介绍当前产品提供的CLI。后端软件存在某个命令，不代表可以直接在VortexROS使用；请以命令参考和当前视图帮助为准。
