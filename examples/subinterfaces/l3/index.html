L3 子接口

L3 子接口按 VLAN 标签区分独立三层链路，可在接口本身配置 IPv4/IPv6 地址和路由协议。它使用 vlan-type；encapsulation 属于 L2 子接口。

完整案例

P1 与 P2 的物理链路分别为 host-p1b12、host-p2b12，两端以 VLAN 700 建立点到点 IP 子网。端口名称来自开发服务器的实际隔离拓扑，在设备上替换为实际 Ethernet 接口。

P1 host-p1b12.700 ── VLAN 700 ── P2 host-p2b12.700
  198.18.170.1/30                  198.18.170.2/30

P1：

system-view
interface host-p1b12.700
 vlan-type dot1q 700
 ip address 198.18.170.1 255.255.255.252
 quit
commit

P2：

system-view
interface host-p2b12.700
 vlan-type dot1q 700
 ip address 198.18.170.2 255.255.255.252
 quit
commit

只接收符合该 VLAN 封装的报文。父端口仍可承载其他不冲突的子接口；不要同时创建会匹配相同标签的 trunk 隐式成员。L3 子接口建立对应 LCP 端点，使 Linux/FRR 使用同一三层接口；不需要加入桥域。

查询与流量

display interface host-p1b12.700
display ip interface brief
display ip routing-table protocol direct
ping -c 3 -a 198.18.170.1 198.18.170.2

实际输出节选：

host-p1b12.700 current state : UP
Line protocol current state : UP
Route Port,The Maximum Transmit Unit is 1500
Internet Address is 198.18.170.1/30
Physical is 802.1Q sub-interface
Encapsulation is dot1q, VLAN 700

本例初次探测为 2/3，随后稳定状态探测为 3 packets transmitted、3 received、0% packet loss。初次丢包记录保留，未用配置和地址存在代替转发验证；这里也不将隔离环境的延迟作为硬件性能结果。

保存与撤销

确认双向路由及流量后执行 save。两端分别撤销：

system-view
undo interface host-p1b12.700
commit

P2 将接口名替换为 host-p2b12.700。删除后核对接口和直连路由消失；需要持久撤销时再 save。

双层标签

两端仍使用同一物理链路，以外标签 702、内标签 70 建立独立三层子网。无需额外配置一个外层 L3 子接口；系统负责 Linux 侧所需的标签层级。

P1：

interface host-p1b12.702
 vlan-type dot1q 702 inner 70
 ip address 198.18.172.1 255.255.255.252
 quit
commit

P2：

interface host-p2b12.702
 vlan-type dot1q 702 inner 70
 ip address 198.18.172.2 255.255.255.252
 quit
commit

真实 CLI 查询：

display interface host-p1b12.702
ping -c 3 -a 198.18.172.1 198.18.172.2

实际输出节选：

host-p1b12.702 current state : UP
Line protocol current state : UP
Internet Address is 198.18.172.1/30
Encapsulation is QinQ, Outer VLAN 702, Inner VLAN 70

3 packets transmitted, 3 received, 0% packet loss

两端必须匹配外、内两层标签。接口编号 702 只标识子接口；标签由 vlan-type 指定。三层视图目前提供上述 dot1q 与 dot1q 内层组合，不应套用 L2 的 encapsulation dot1ad 语法。

删除时分别执行 undo interface host-p1b12.702、undo interface host-p2b12.702 并提交。共享同一外标签的其他内层仍存在时，系统保留所需的 Linux 外层；删除最后一个内层时清理该辅助对象。它不是独立用户配置，不应手工配置 IP 或加入桥域。

父接口生命周期与删除结果

本次在保留两端配置的情况下，关闭 P1 父接口并提交：普通 dot1q700 和 QinQ702 均显示 Down；恢复父接口后，两者恢复 Up。恢复后的首次探测分别为 2/3，随后稳定状态两者均为 3/3。父接口状态由现有配置的有效管理状态传给子接口，不通过删除子接口地址来实现暂停。

仅执行 undo vlan-type 而保留子接口，会在提交时得到实际错误：

Error: validate candidate: validate canonical configuration: sub-interface host-p1b12.700 has incomplete VLAN encapsulation

失败时 Running 仍保留原 VLAN 与地址；补回原封装后可以正常提交。完整撤销使用 undo interface。本轮已在两端删除 .700/.702 并提交：实际接口清单与 Linux VLAN 清单均不再包含它们，198.18.170.0/30、198.18.172.0/30 的实验直连路由也已删除。最后一个 QinQ 内层删除后，没有残留辅助外层。这里的删除结论来自成功的完整清单查询，不是查询失败后未匹配到名称。
