# 维护材料

cli-coverage.tsv 保留先前命令输入与日志文件的对应关系，供维护追踪。命令出现在终端日志中不等于对应功能已完成验收。

本目录不属于 Sphinx 文档源，不随用户手册站点发布。面向用户的配置、检查与撤销以 docs 下的功能页和案例为准。

`third-cli-coverage.tsv` 是第三轮真实 CLI 全量阶段的逐路径结果，共 852 条。保留原始状态，`PASS` 表示完整通过，`PASS_SCOPE` 表示按所测范围通过，`PARTIAL` 表示仍有子场景未通过。后续补验和最终整包验证见 [Debug 9 版本说明](../docs/release/debug9.md)，未将这些后续结果反写进原始全量台账。
