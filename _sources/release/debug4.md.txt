# Debug 4

Debug 4 更新控制层，配套 VPP、FRR 和 Kea 版本与 Debug 3 相同。统一安装包只更新实际版本发生变化的组件，既有配置保留。安装步骤见[升级与回退](../installation/07-upgrade-uninstall.md)。

## 接口查询与预配置

接口列表、描述、统计、IP 简表和补全仅包含 VPP 接口、逻辑接口及 `user-defined` 预配置接口。仅由宿主 Linux 管理的设备不自动显示，也不会因隐藏而删除其已有配置。

在数据面接管前，可以使用 `interface user-defined Ethernet0` 预配同名接口，接管后显示实际 VPP 状态。配置仍保存为 `interface Ethernet0`。范围、限制及操作见[接口](../operator/03-interfaces-l2.md)。

## 配置编辑与删除

删除逻辑接口时，一并撤销其子接口、关联 NAT 绑定、Proxy ARP 范围和 DHCP 接口配置；其他接口及全局共享策略保留。存在不允许自动清理的独立引用时，应先解除引用；命令失败不会留下部分候选修改。VPN 相关接口删除使用相同边界。

`display this` 和当前配置查询保留私有候选隔离及跨会话更新，减少重复读取。完整关键字及参数名称不再被隐藏子命令误改写。

## 恢复与运行查询

隧道实际状态查询只补读相关 VPN 的目标地址；已有完整运行信息时直接使用该信息。Linux-only 的独立配置恢复不要求 VPP 已启动；VPP 接管的配置仍需数据面连接和正确的接口库存。

普通 CLI 启动用于查看和编辑配置，不再隐式进行一套局部接口重放。正常启动恢复及显式配置恢复仍使用产品原有流程。

## 验证范围

本版完成接口配置删除、会话隔离、ACL/BGP 规则、配置回放、接口显示和后端回读的相关定向验证。Linux ICMP 禁止与撤销使用实际探测确认；IPv6、VRF 和 RA 路由清理回读通过；双栈邻居参数补偿、桥域拒绝后停止下发、旧 QinQ 默认子接口的选择性清理通过。

本版不改变转发协议默认值，不宣称转发性能提升或无损升级。具体软件安装包、升级与回退实测及适用边界见 [Debug 4 Release](https://github.com/opennw-rui/VortexROS/releases/tag/v0.30-dev-debug4)。
