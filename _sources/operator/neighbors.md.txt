# ARP 与 ND

检查和管理 IPv4 ARP 与 IPv6 ND 邻居。

`display arp` 的 `AGE(M)` 表示后端报告的邻居条目距上次更新的时间，按分钟取整显示，不是剩余过期时间。小于30秒或后端没有提供年龄时留空；静态项和接口自身地址的年龄也留空。

[命令参考](reference/neighbors.md)

## ARP、ND 与路由的关系

IPv4 使用 ARP 将同链路下一跳地址解析为 MAC；IPv6 使用 RFC 4861 邻居发现。路由决定下一跳和出口，邻居表提供该链路的二层目的地址。远端目的前缀通常解析网关，而不是为每个远端主机建立直接邻居。

| 类型 | 作用 | 规划重点 |
| --- | --- | --- |
| 动态 | 从协议交互学习并维护状态 | 接口、VPN 和链路可达性 |
| 静态 | 人工固定 IP/MAC/接口关系 | 对端变更后需要同步维护 |
| 容量 | 限制邻居学习和回收规模 | 与数据面内存及实际规模配合 |

IPv6 邻居发现还承载地址重复检测、路由器通告等功能，不应直接套用禁止全部 ICMP 的 IPv4 经验。业务不通时先查路由，再查所选出口的邻居；解析完成只证明二层邻居关系，不证明对端回程。
