# QinQ

在客户标签外加一层服务标签，隔离不同客户的二层业务。

[命令参考](reference/vlan.md)

~~~{toctree}
:maxdepth: 1

qinq-flexible
~~~

## 工作原理与组网选择

QinQ 通过外层服务标签携带客户 VLAN。客户侧 C-VID 与服务侧 S-VID 分开规划，服务网络可以在不改变客户 VLAN 含义的情况下区分接入业务。IEEE 802.1ad 常用外层 TPID 0x88a8，双 0x8100 标签形式与其匹配条件不同。

父端口的简单 QinQ 用于整个客户口映射，灵活 QinQ 按客户 VLAN 集合选择服务；显式 L2 子接口用于匹配核心侧的单/双标签集合。这是两种入口，不应把一段子接口配置当作完整的父端口灵活 QinQ 功能。多个内层业务共用一个桥域还意味着共享该二层学习范围，不能仅靠不同内层标签假定已经隔离。

额外标签占用链路 MTU。规划两端的匹配、入方向移除和出方向恢复方式；多内层业务不可在去掉所有标签后期待出口自动猜回原 C-VID。相关限制和完整双端步骤见下列说明与案例。

## 支持范围

父接口的基本 QinQ 与子接口的多内层匹配不是同一个功能。按接入方式选择：

| 接入方式 | 当前能力 | 限制 |
| --- | --- | --- |
| 父接口 `dot1q-tunnel` | 整个客户口归属一个服务 VLAN，客户标签透传并在核心侧增加服务标签 | 不按客户 VLAN 选择服务；不能同时创建 VLAN 子接口 |
| 父接口灵活 QinQ | Hybrid 客户口按单个/列表/范围 C-VLAN 映射 S-VLAN | 仅匹配单标签客户报文；同口分类不可冲突，详见独立页面 |
| L2 子接口 | 固定外层 VID，内层可为单值、列表、范围或 `any`，并可配置标签重写 | 多内层和 `any` 必须选择 `rewrite pop single` 或 `rewrite pop none` |
| L3 子接口 | 固定外层 VID，可再指定一个固定内层 VID | 不支持内层列表、范围或 `any` |

L2 子接口的 `ce-vid 10 12 to 15` 表示匹配内层 VLAN 10、12、13、14、15；
`ce-vid any` 表示任意内层 VLAN。一个业务子接口承载其匹配集合，不需要用户逐个建立子接口。
这类匹配仍使用固定外层标签，不提供父接口上的任意 VLAN 映射规则。

多内层业务移除全部标签后，无法在出口还原原来的不同客户标签，因此不允许使用
`rewrite pop double`。需要保留内层标签时选择 `single`，需要保留完整标签时选择
`none`。多个客户 VLAN 加入同一桥域后共享二层学习范围，并不自动成为相互隔离的业务。

完整配置、实际查询和网关限制见[L2 子接口](subinterfaces-l2.md#固定外层多个内层的-qinq)；
固定双标签的三层终结见[L3 子接口](subinterfaces-l3.md)。

## 配置与影响

简单QinQ端口使用VRP风格的`dot1q-tunnel`。`port default vlan`把整个父接口作为唯一客户侧成员加入对应bridge-domain；不创建隐藏子接口，也不在父接口执行标签改写。对端trunk按外层服务VLAN分类并对称移除/恢复S-Tag，因此客户侧未打标签报文转为单层S-Tag，已有C-Tag的报文转为S-Tag+C-Tag。配置示例：

```text
vlan batch 200
interface Ethernet 2
 portswitch
 port link-type dot1q-tunnel
 port default vlan 200
```

`dot1q-tunnel`父接口接管该端口的完整客户侧分类空间，包括未打标签和所有客户VLAN标签，因此不能同时在该父接口上创建 L2 或 L3 VLAN 子接口。

显式子接口使用的实际外层 VID 与全局 VLAN 对象互斥，适用于所有父接口和 dot1q/dot1ad/QinQ，配置顺序不影响结果。子接口实例后缀、bridge-domain编号及内层客户VID独立，不占用全局VLAN编号。不同父接口可复用没有全局VLAN对象的同一外层VID；同一父接口的匹配集合不能重叠。系统为交换端口派生的内部对象不按显式子接口处理。

显式 L2 子接口还支持固定外层、多个内层 VID 或任意内层的[显式 L2 子接口](subinterfaces-l2.md#固定外层多个内层的-qinq)。它复用同一套原生子接口分类，不是新的父端口规则引擎，也不改变上述简单 QinQ 端口语义。多内层的对称标签恢复有限制，提交前必须明确选择保留标签或只移除外层，不能直接沿用固定双标签的 pop2 默认值。

查看 `display vlan` 核对服务 VLAN 和客户侧成员。
