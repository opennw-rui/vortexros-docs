# 地址池 PAT

把多个连接转换到地址池地址及分配的端口，不依赖出口接口地址。公网池地址必须能从外部路由回到 P1。

## 行为与限制

池内地址由地址池对象定义，PAT 范围缺省 10000–65535；耗尽时新连接失败，不会自动使用范围外的端口。删除地址池前必须解除策略引用。

此功能需要 VPP。配置写入 Candidate，`commit` 后参与下发，`save` 保存已提交配置；重启后从启动 CFG 恢复。缺省不创建 NAT 策略或接口绑定。

## 配置、显示与撤销

[完整独立案例](../../examples/nat/pool-pat.md)包含拓扑、网关和端点前提、完整策略、实际 display 输出、HTTP 往返及撤销。以下是本功能实际验收的转换结果节选：

~~~text
host-p1a12/outbound  FIB:0 -> FIB:0  Policy:LAB-SNAT(4124874345)/10  Action:SNAT-PAT
198.18.11.2:44510 -> 198.19.80.2:8080  =>  198.19.81.1:20058 -> 198.19.80.2:8080
~~~

P3 到 P2 的 HTTP 返回 200；P2 日志看到 198.19.81.1。转换端口 20058 在配置的 20000–20063 内。端口不是固定分配值。
