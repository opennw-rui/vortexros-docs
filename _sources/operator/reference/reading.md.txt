# 阅读说明


- `视图`表示命令可以在哪些 CLI 视图中使用；`任意允许视图`表示命令可在多个合法视图中使用。
- 受管 SSH 用户按本地 AAA 角色访问 CLI；Linux 凭据尚未完整投影时拒绝受管 CLI 授权。独立 Linux 救援入口使用 UID 0，见[账号管理](../aaa.md)。
- `CLI 帮助`保留设备实际的 `?` 提示文字。
- 完整配置步骤、输出样例和故障处理请进入对应配置指南章节。

配置命令先写入本会话 Candidate，提交后才影响 Running。即时运维命令可直接改变运行状态。用 ? 查看当前视图合法参数。

## 参数表

命令参考按当前 0.29-dev Registry 的实际参数树列出子命令、位置、可选性、组合标记和设备帮助。相同命令在不同视图有不同参数时分别列出，不把 BGP、WireGuard、NAT 的同名 peer/rule 等语义混在一起。

参数表的帮助文字保留设备原文；配置影响、有效默认值、依赖、流量结果和撤销步骤由各功能指南说明。参数表不是新的产品命令，也不代表每种组合均完成独立动态验收。

表中“可组合/可重复”来自 CLI 提示树，不改变上方完整语法或处理器校验。运行库存（已有接口、策略名等）不是固定的合法范围，需在实际设备输入 `?` 查看。未配置的默认项通常不显示在 config 中；`undo` 的删除对象与恢复缺省两类行为以具体命令/功能说明为准。
